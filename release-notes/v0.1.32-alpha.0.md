# AgentTeams v0.1.32-alpha.0

This opt-in preview targets DeepSeek Harness `0.2.3-alpha.2` and is published through npm's `next` channel. The ordinary recommendation remains AgentTeams `0.1.31` on Harness `0.2.2-rc.5`.

- Use Harness's centralized `auth: 'required'` WebServer policy for every AgentTeams route.
- Select member models through the native `Agent.model.select` API.
- Exercise tool calls through the separate native tool executor and the batched tool runtime API.
- Adapt retry and session-projection fixtures to asynchronous projection handles.
- Require Node `24.22.3` or a supported Node 26 release and keep the full DSH dependency cohort on `0.2.3-alpha.2`.

## 中文

这是面向 DeepSeek Harness `0.2.3-alpha.2` 的选择性预览版，通过 npm `next` 渠道发布。普通用户的推荐组合仍是 Harness `0.2.2-rc.5` 和 AgentTeams `0.1.31`。

- 所有 AgentTeams Web 路由改用 Harness 集中的 `auth: 'required'` 鉴权策略。
- 通过原生 `Agent.model.select` API 选择成员模型。
- 使用独立的原生工具执行器和批量工具运行时 API。
- 适配异步会话 projection handle 与新版重试运行时。
- 要求 Node `24.22.3` 或受支持的 Node 26，并将整组 DSH 依赖锁定到 `0.2.3-alpha.2`。
